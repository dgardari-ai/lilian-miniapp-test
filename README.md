# LILIAN Mini App — v0.1

Статус: локальный тестовый кандидат 28.09.2026. Не опубликован, не подключён к Telegram и не принят Галой/Катериной.

## Задача

Быстро проверить одну гипотезу: вместо листания большого ассортимента женщина начинает с собственной танго-ситуации и получает несколько реальных вариантов LILIAN, после чего передаёт выбранный вариант в человеческую консультацию.

Миниапп не является интернет-магазином, ИИ-стилистом, виртуальной примерочной или системой автоматического определения посадки.

## Сценарий v0.1

1. Выбрать ситуацию: практика/урок, милонга, марафон/поездка, подготовка к выступлению.
2. Выбрать способ: цельный образ, комбинации, показать разное.
3. Получить три варианта из подтверждённой рабочей подборки.
4. Выбрать один вариант для разговора.
5. При желании добавить размер, рост и вопрос.
6. Открыть официальный контакт @rubiamorenadress с подготовленным сообщением.

## Почему только три формы

В архиве бренда материала значительно больше, но актуальная полная матрица «модель × ткань × цвет × размер × длина × цена» не подтверждена. Для первого теста используются только уже разобранные в рабочем сайте формы:
- платье «Лилиан»;
- платье с кейп-рукавом;
- комплект: топ «Фонарик» + юбка «Ласточкин хвост».

Это ограничение охвата, а не вывод о полном ассортименте LILIAN.

## Основание

- Телеграм-исследование Rubia&Morena и LILIAN, снимок по 04.09.2026.
- Интервью Галы и Катерины, блоки 1–9, 10–11.09.2026.
- ПЗ сайта LILIAN v0.2 и локальный журнал подпроекта.
- models.js и разрешённые изображения действующего локального прототипа сайта.

Особенно использованы авторские положения: LILIAN упрощает сложный выбор; образ бумажной куклы как метафора комбинирования; ситуации «практика завтра», марафон и тренировочная форма; личная консультация остаётся существенной частью выбора.

## Достоверность

Миниапп сознательно не показывает актуальные цены и наличие. Посадку, размер, ткань, цвет, текущую цену и срок должна подтвердить команда LILIAN.

Переход к подготовке выступления не означает автоматического соответствия выбранной вещи конкретному сценическому платью.

## Проверка

Пройден мобильный интерактивный маршрут в Chromium с эмуляцией 390×844:
intro → марафон/поездка → хочу комбинировать → результаты.

Проверено:
- viewport 390 px, горизонтальное переполнение отсутствует;
- все четыре экрана переключаются;
- выдаются три карточки;
- для сценария «марафон + комбинировать» первым выбирается комплект;
- кнопка выбора и подготовка обращения присутствуют;
- JavaScript проходит синтаксическую проверку;
- все локальные изображения существуют.

Не проверены: реальный Telegram WebView на iPhone/Android, фактическая передача текста в @rubiamorenadress, установка через конкретного бота, реакция Галы и пользовательниц.

## Файлы

- index.html — интерфейс и тексты;
- styles.css — визуальная система;
- app.js — сценарий, правила выдачи, Telegram-переход;
- assets/images/ — только изображения, используемые этой версией;
- robots.txt — запрет индексации теста;
- output/ — локальные снимки проверки, в публичную сборку не включать.

Для локального просмотра: статически отдать папку MINIAPP через HTTP-сервер.

Публичное размещение и подключение к Telegram требуют отдельного разрешения и фактической проверки выбранного маршрута.
